# LinkedIn post draft

I built a prototype called Virasat.

The idea: you open the app in a new city, it finds where you are, and shows the heritage sites around you. Each site has photo and reel ideas to recreate, so your trip is not just "I stood there".

The part I care most about: a student can sign up as a local guide, set an hourly rate, and get booked by visitors. The payment goes directly to the guide. It is a way for undergraduates to earn from what they already know about their city.

What I built it with:
- Node.js and Express for the API
- Leaflet and the browser Geolocation API for the live map
- Razorpay Orders and Route for split payments to guides
- Vanilla JavaScript on the frontend, no build step

What I learned:
- Instagram has no simple public API for trending posts, so I curated shot ideas and linked to hashtags. The proper route is the Graph API.
- Payments need verification on the server. The browser cannot be trusted to say "paid".
- Trust matters more than features when strangers meet. Guide verification is the first thing on my roadmap.

It is a prototype, and the code is open. I would like feedback from people who travel, guide, or build marketplaces.
